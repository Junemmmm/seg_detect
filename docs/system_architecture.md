# 路沿检测系统架构设计

## 1. 系统总体架构

### 1.1 硬件架构
- ZYNQ 7015开发板
  - PS：ARM Cortex-A9处理器
  - PL：FPGA逻辑资源
- RealSense D455相机
- 主机PC

### 1.2 功能分配

#### ZYNQ端
1. 数据接收
   - 读取.bag文件数据
   - 数据预处理和格式转换

2. 模型推理
   - YOLOv8n模型（INT8量化）
   - best1.pt模型（INT8量化）
   - 并行推理加速

3. 结果传输
   - 推理结果打包
   - 通过高速接口传输到PC

#### PC端
1. 点云处理
   - 图像到点云映射
   - 点云降采样和滤波
   - 边缘点提取
   - 曲线拟合

2. 可视化显示
   - 检测结果显示
   - 点云可视化
   - 系统状态监控
