# ZYNQ7015在路沿检测项目中的应用设计

## 1. 项目概述

当前路沿检测项目主要功能包括：
- 使用RealSense D455相机采集RGB-D数据
- 使用YOLOv8n（8MB）进行路沿实例分割
- 使用best1.pt（22MB）进行目标检测

后续将逐步实现：
- 将分割后的图像映射到点云中
- 提取路沿边缘点并生成贝塞尔曲线
- 中心点定位

通过分析代码性能，发现当前最主要的计算瓶颈是：
- 两个YOLO模型的并行推理（占用大量计算资源）
- RealSense D455相机的实时数据采集和处理

## 2. ZYNQ7015硬件特性

ZYNQ7015是赛灵思（Xilinx）的异构SoC，集成了：
- 双核ARM Cortex-A9处理器（PS部分，最高频率866MHz）
- 可编程逻辑FPGA（PL部分，约74K逻辑单元）
- 高速AXI总线接口连接PS和PL
- 丰富的I/O接口（PCIe、USB、以太网等）

## 3. 系统架构设计

### 3.1 整体架构

```
+----------------------------------+
|            ZYNQ7015             |
|  +------------+  +------------+ |
|  |    ARM     |  |    FPGA    | |
|  | Cortex-A9  |<=>|   加速器   | |
|  | (控制逻辑) |  | (算法加速) | |
|  +------------+  +------------+ |
+----------------------------------+
        ^                ^
        |                |
+---------------+  +---------------+
|  RealSense   |  |   存储设备    |
|   相机/数据   |  | (.bag文件)   |
+---------------+  +---------------+
```

### 3.2 功能分配

**ARM处理器(PS)负责：**
- 系统控制和调度
- 数据I/O处理（读取.bag文件）
- 用户界面和交互
- 结果显示和存储

**FPGA(PL)负责：**
- YOLO模型推理加速
- 点云处理加速
- 图像预处理和后处理
- 贝塞尔曲线计算加速

## 4. 硬件加速方案

### 4.1 YOLO模型推理加速

当前项目使用两个YOLO模型：YOLOv8n（8MB）用于路沿分割，best1.pt（22MB）用于目标检测。在FPGA上实现：

1. **模型量化与优化**
   - 将FP32精度降至INT8，减少计算量
   - 针对FPGA优化两个模型的网络结构
   - 实现模型并行推理

2. **卷积运算加速器**
   - 设计专用卷积计算单元
   - 实现并行卷积核计算
   - 使用脉动阵列（Systolic Array）架构

3. **内存访问优化**
   - 设计高效缓存结构
   - 优化数据流，减少内存访问

### 4.2 点云处理加速

点云处理涉及大量三维坐标变换和空间计算：

1. **点云映射加速**
   - 实现并行坐标变换单元
   - 加速`get_point_cloud_from_mask`函数

2. **点云滤波与降采样**
   - 实现体素化处理硬件加速
   - 优化`get_voxelized_point_cloud_from_mask`函数

### 4.3 曲线拟合与绘制加速

1. **贝塞尔曲线计算加速**
   - 实现专用数学运算单元
   - 加速`draw_bezier_curve`和`extract_and_draw_leftmost_points`函数

2. **RANSAC算法加速**
   - 并行化RANSAC迭代过程
   - 加速异常点检测

## 5. 软件架构调整

为适配ZYNQ7015，需要对软件架构进行调整：

1. **操作系统选择**
   - 使用嵌入式Linux（如Petalinux）
   - 配置实时性能优化

2. **驱动开发**
   - 开发FPGA加速器驱动
   - 实现PS与PL之间的数据传输接口

3. **API重构**
   - 修改现有Python代码，增加硬件加速接口
   - 开发C/C++库封装硬件加速功能

4. **算法移植**
   - 将关键算法从Python移植到C++/HLS
   - 使用Xilinx Vitis HLS工具进行高层次综合

3. **系统集成度提高**

   - 系统体积和重量显著减小

## 8. 挑战与解决方案

### 8.1 主要挑战

1. **模型量化精度损失**
   - 解决方案：量化感知训练，混合精度计算

2. **内存带宽限制**
   - 解决方案：优化数据流，减少内存访问，使用片上缓存

3. **开发复杂度高**
   - 解决方案：使用HLS工具，降低硬件开发难度

### 8.2 风险管理

1. **性能不达预期**
   - 缓解措施：分阶段实现，先优化最关键部分

2. **开发周期延长**
   - 缓解措施：采用敏捷开发方法，快速迭代
